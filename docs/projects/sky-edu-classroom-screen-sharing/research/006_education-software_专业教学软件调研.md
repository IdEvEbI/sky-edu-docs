## 1. 联想传奇因特网电子教室

### 1.1 官方网站和主要功能

联想传奇因特网电子教室（也称传奇电子教室软件）的官方网站为 [http://www.legendeclass.com/](http://www.legendeclass.com/)。该软件是针对学校、企事业单位教育教学和职业培训设计的多媒体教学工具。

主要功能包括：屏幕广播（教师将屏幕同步到学生机，支持锁定或协同操作）、学生示范（学生屏幕广播到全班）、视频广播、查看学生屏幕、锁定学生操作、文件分发和回收、联机讨论、在线考试、机房管理和个性化设置（如背景音乐、学生分组）。它集教学、练习、考核于一体，支持因特网共享（通过 Modem 实现全教室上网），适用于计算机教室和多媒体机房。

### 1.2 是否支持局域网模式？

支持。该软件设计用于局域网环境，通过本地网络实现教师机和学生机的连接和控制，无需互联网即可运行核心功能。

### 1.3 屏幕共享和监控功能

屏幕共享功能包括教学演示（教师屏幕实时广播到学生机，支持全屏或窗口模式）、学生示范（反向共享学生屏幕）和视频广播。监控功能包括查看学生屏幕（实时监控多台学生机）、锁定学生（防止操作）和机房管理（远程关机、重启）。传输采用先进压缩技术，确保速度和稳定性。

### 1.4 并发用户数限制

免费版支持 6 用户同时使用；商业版或高级版可扩展到更多（如教室规模），但具体上限取决于许可证和网络容量，通常适用于 30-50 台学生的标准教室。

### 1.5 硬件要求和部署方式

**硬件要求**：教师机和学生机需 Windows 操作系统（支持 Win7+），最低配置为 Intel Pentium 处理器、512MB RAM、100MB 硬盘空间；推荐局域网带宽 100Mbps 以上。

**部署方式**：教师端和学生端分别安装软件，通过局域网自动发现和连接，支持一键部署（如网络同传工具批量安装）。可选集成 VOD 系统和电子教案。

### 1.6 优劣势分析

**优势**：免费基础版易上手、功能全面（教学+管理一体）、稳定可靠（针对教室优化）、支持因特网共享降低成本。

**劣势**：界面较老旧（可能不适应现代 UI）、依赖 Windows（跨平台差）、缺乏云端支持（不适合远程教学）、扩展性有限（免费版用户少）。

## 2. 必捷多媒体协作系统

### 2.1 官方网站和主要功能

必捷多媒体协作系统的官方网站为 [https://www.bijienetworks.com/](https://www.bijienetworks.com/)。该系统专注于无线投屏和多屏协作解决方案。

主要功能包括：无线投屏（手机/电脑到大屏）、分组研讨互动、多路同时投影、音视频传输、白板标注、文件共享、BYOM（Bring Your Own Meeting）会议模式，以及集成智能会议室、智慧教室和 AR/VR 应用。支持高清 4K 传输和跨设备互联。

### 2.2 是否支持局域网模式？

支持。该系统基于 Wi-Fi 网络实现局域网内无线连接，支持 LAN 直连，无需互联网即可投屏和协作。

### 2.3 投屏协议支持

支持多种协议，包括 AirPlay（iOS/macOS）、Miracast（Android/Windows）、Googlecast（Chrome）、DLNA、BJCast（自主协议），以及网页投屏、企业微信投屏。允许多路同时投屏和互动。

### 2.4 并发用户数限制

支持多路同时投影（通常 4-9 路，视硬件而定，如 BJ66 设备支持多用户），无明确上限，但实际取决于设备性能和网络带宽，适用于中型会议室（20-50 人）。

### 2.5 硬件要求和部署方式

**硬件要求**：需要必捷硬件设备（如 BJ66 盒子或会议一体机），支持 Windows/Android/iOS/macOS，Wi-Fi 5/6 网络，推荐 4K 显示屏。

**部署方式**：安装 SDK 或硬件盒子，通过局域网连接设备，支持开放 API 集成第三方系统，一键配置。

### 2.6 优劣势分析

**优势**：高清低延迟、多协议兼容、易集成（SDK 开放）、适用于多种场景（如会议/教室）。

**劣势**：依赖硬件（成本高）、设置稍复杂（需专业配置）、免费版有限（商业需订阅）。

## 3. EV 屏幕共享

### 3.1 并发用户数限制

根据调研，个人版支持最多 20 台设备并发连接，商业版扩展到 50 台，支持多设备同步共享。

### 3.2 技术架构分析

EV 屏幕共享采用局域网内直连架构（P2P 模式），延迟低至 200ms，支持端到端加密和实时同步。核心技术包括高效视频压缩（H.264/H.265）和网络发现协议，轻量级软件（安装包 <40MB），兼容 Windows 7+、Android/iOS。架构分为客户端（手机/电脑）和服务器端（可选监控模式），通过 UDP/TCP 混合传输实现屏幕共享和文件传输，无需云端依赖。

### 3.3 与我们的差异化优势

我们的软件（基于 Python/Flutter 等）支持自定义教育功能（如作业布置、点名、跨平台移动适配），而 EV 更注重通用共享（无教育专属模块）。

**我们的优势**：开源潜力、免费扩展性强、支持离线/LAN 优化；EV 的劣势在于功能单一（无集成考试/分析）。我们的 MVP 迭代快，EV 依赖局域网直连但无高级数据分析。

### 3.4 市场定位分析

EV 屏幕共享定位于局域网轻量级工具，针对无纸化会议、多媒体课堂、电子机房和生产车间，强调操作简单（一键直连）和低成本。市场目标为中小企业、教育机构和个人用户，商业版适合中型团队。相比竞争产品（如 TeamViewer），EV 更专注 LAN 低延迟，非远程优先；市场份额小但用户友好，增长依赖免费版推广。

## 4. 综合对比分析

### 4.1 局域网支持对比

| 产品        | LAN 支持    | 并发限制 | 硬件依赖     | 成本       |
| ----------- | ----------- | -------- | ------------ | ---------- |
| 联想传奇    | ✅ 原生支持 | 30-50 台 | Windows 系统 | 免费基础版 |
| 必捷        | ✅ 支持     | 20-50 人 | 专用硬件     | 商业订阅   |
| EV 屏幕共享 | ✅ 原生支持 | 20-50 台 | 无特殊要求   | 商业版付费 |

### 4.2 技术特点对比

**联想传奇**：功能最全面，专为教育设计，但界面老旧，跨平台差。

**必捷**：技术先进，多协议支持，但硬件依赖强，成本高。

**EV 屏幕共享**：轻量级，延迟低，但功能单一，缺乏教育定制。

### 4.3 市场机会

现有产品在以下方面存在不足：

- 界面现代化程度低
- 跨平台支持有限
- 教育场景定制不足
- 成本控制能力弱
- 开源友好性差

这为我们的产品提供了明确的市场机会。
