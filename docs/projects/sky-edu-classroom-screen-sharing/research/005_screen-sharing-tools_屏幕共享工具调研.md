# 屏幕共享工具调研

> 适用范围：项目决策者、技术团队、产品经理  
> 目标：深度分析主流屏幕共享工具的技术特点和优劣势  
> 责任人：技术架构师  
> 首次创建：2025-10-21  
> 最近更新：2025-10-21  
> 版本：v1.0

## 1. TeamViewer

### 1.1 官方网站和主要功能

TeamViewer 的官方网站为 [https://www.teamviewer.com/en/](https://www.teamviewer.com/en/)。主要功能包括远程访问和控制、文件传输、在线协作（支持音频/视频会议）、无人值守访问、集成第三方应用（如 Microsoft Teams、Salesforce）、AI 驱动功能（如 Session Insights 自动总结会话）和增强现实（AR）支持。软件支持跨平台连接（Windows、macOS、Linux、iOS、Android），并提供安全功能如双因素认证、端到端加密和白名单/黑名单。

### 1.2 是否支持局域网模式？

支持。通过设置中的"Incoming LAN Connections"选项，选择"Accept"或"Accept exclusively"即可启用 LAN 模式，仅使用本地 IP 地址连接，无需互联网。

### 1.3 屏幕共享技术实现

屏幕共享基于 WebRTC-like 技术，实现低延迟音视频传输，支持实时互动和云录制。结合 PPT 插件嵌入，确保高效压缩和流畅显示，尤其适用于高峰期。

### 1.4 并发用户数限制

Business 和 Premium 许可证每个通道支持 1 个并发会话（通道），Corporate 支持 3 个通道。每个连接最多 15 个会话（标签）。免费版无商业并发限制，但商业使用需付费。

### 1.5 商业模式和价格

免费用于非商业用途。商业模式为订阅制：Business \$50.90/月（单用户）、Premium \$112.90/月、Corporate \$229.90/月（年付）。企业版可添加通道。定价基于并发会话和用户数，包含免费试用。

### 1.6 优劣势分析

**优势**：易用性强、跨平台兼容、安全性高（加密、集成）、远程支持高效，节省时间和成本。

**劣势**：商业定价高、连接问题（如延迟或中断）、新界面不友好、合同灵活性差。

## 2. AnyDesk

### 2.1 官方网站和主要功能

AnyDesk 的官方网站为 [https://anydesk.com/en](https://anydesk.com/en)。主要功能包括远程桌面访问、屏幕共享、文件传输、无人值守访问、会话录制、访问控制、白板、Wake-on-LAN、REST API 集成和自定义用户界面。支持跨平台（Windows、macOS、Linux、iOS、Android），强调低延迟和高帧率。

### 2.2 是否支持局域网模式？

支持。通过设置启用"Allow direct connections"，允许 LAN 内直接连接，无需互联网。

### 2.3 屏幕共享技术实现

基于 DeskRT 编解码器，实现高帧率（60 fps）、低延迟和高效带宽使用，支持实时协作和跨平台共享。

### 2.4 并发用户数限制

基于许可证：Solo 1 个并发连接、Standard 1 个（可添加至 20+）、Advanced/Ultimate 支持更多。免费版限 3 设备、1 并发。

### 2.5 商业模式和价格

免费用于个人。商业模式为订阅制：Solo \$22.90/月、Standard \$29.90/月、Advanced \$79.90/月（年付）。基于并发连接，按地区调整。

### 2.6 优劣势分析

**优势**：快速、轻量、低延迟、易用、安全（双因素认证）、跨平台。

**劣势**：慢网络下延迟、免费版限功能、高级版贵、偶发断连。

## 3. VNC Connect

### 3.1 官方网站和主要功能

VNC Connect 的官方网站为 [https://www.realvnc.com/en/](https://www.realvnc.com/en/)。主要功能包括远程访问、屏幕共享、文件传输、无人值守访问、多监视器支持、会话录制、多语言支持和 Linux 虚拟桌面管理。支持跨平台（Windows、macOS、Linux、Raspberry Pi）。

### 3.2 是否支持局域网模式？

支持。通过直接连接模式，使用本地 IP/主机名在 LAN/VPN 内连接，无需云。

### 3.3 屏幕共享技术实现

基于 VNC 协议，实现远程控制和屏幕更新，支持端到端加密和实时互动。

### 3.4 并发用户数限制

基于订阅：Essentials/Plus/Premium 按并发会话限额（团队共享），如 Premium 无限会话，企业自定义。

### 3.5 商业模式和价格

免费用于非商业。商业模式为订阅制：Essentials \$3.39/月/设备、Plus \$4.19、Premium \$5.49（年付）。企业自定义。

### 3.6 优劣势分析

**优势**：安全（加密、多因素）、可靠、跨平台、易用。

**劣势**：性能问题（延迟）、定价按设备高、设置复杂。

## 4. 综合对比分析

### 4.1 局域网支持对比

| 产品        | LAN 支持 | 技术实现        | 并发限制        |
| ----------- | -------- | --------------- | --------------- |
| TeamViewer  | ✅ 支持  | WebRTC-like     | 15 会话/连接    |
| AnyDesk     | ✅ 支持  | DeskRT 编解码器 | 1-20+ 并发      |
| VNC Connect | ✅ 支持  | VNC 协议        | 无限（Premium） |

### 4.2 成本对比

| 产品        | 免费版     | 商业版价格     | 适用场景     |
| ----------- | ---------- | -------------- | ------------ |
| TeamViewer  | 非商业免费 | \$50.90/月起   | 企业级应用   |
| AnyDesk     | 个人免费   | \$22.90/月起   | 中小型企业   |
| VNC Connect | 非商业免费 | \$3.39/月/设备 | 成本敏感场景 |

### 4.3 技术特点对比

**TeamViewer**：功能最全面，企业级安全，但成本最高。

**AnyDesk**：性能优秀，成本适中，适合大多数场景。

**VNC Connect**：成本最低，开源友好，但性能相对较差。
